# AI Recruiter Email Automation with n8n

An automated **recruiter outreach workflow** built with **n8n**, **Gemini AI**, and **Gmail**.

The workflow reads recruiter leads, cleans and validates the data, generates a simple personalized email using an LLM, and automatically sends the message through Gmail.

## 🚀 Workflow Overview

The automation follows this process:

```text
Manual Trigger
      │
      ▼
  Read Leads
      │
      ▼
  Clean Data
      │
      ▼
IF Email Exists?
      │
      ├── FALSE → Skip
      │
      └── TRUE
            │
            ▼
       IF Not Sent?
            │
            ├── FALSE → Skip
            │
            └── TRUE
                  │
                  ▼
          Loop Over Items
          Batch Size: 2
             │
             │ LOOP
             ▼
       Message a Model
             │
             ▼
       Parse AI Output
             │
             ▼
            Gmail
             │
             │
             └──────────────► Loop Over Items
                              │
                              ├── LOOP → Message a Model
                              │
                              └── DONE → End
```

## 🎯 Objectives

The main objectives of this workflow are to:

* Automate recruiter email outreach.
* Process and validate recruiter lead data.
* Generate personalized email content using Gemini AI.
* Avoid sending emails when no valid email address is available.
* Prevent sending emails that have already been sent.
* Process multiple leads automatically.
* Send generated emails through Gmail.

## ⚙️ Technologies

* **n8n** – Workflow automation
* **Google Gemini** – AI-powered email generation
* **Gmail** – Email delivery
* **LLM** – Personalized email content generation

## 🔄 Workflow Steps

### 1. Manual Trigger

The workflow starts with a manual trigger, allowing the automation to be tested or executed when needed.

### 2. Read Leads

The workflow retrieves the recruiter lead data containing information such as:

* Recruiter name
* Company
* Email address
* Additional lead information
* Email status

### 3. Clean Data

The lead information is cleaned and prepared before processing.

This step helps normalize the input data and ensures that the following nodes receive structured information.

### 4. Check Email Availability

The workflow checks whether a valid email address exists.

```text
Email Exists?
│
├── No  → Skip Lead
│
└── Yes → Continue
```

Leads without an email address are excluded from the email-sending process.

### 5. Check Sending Status

The workflow verifies whether an email has already been sent to the lead.

```text
Not Sent?
│
├── No  → Skip Lead
│
└── Yes → Continue
```

This prevents unnecessary duplicate outreach.

### 6. Loop Over Leads

The **Loop Over Items** node processes the leads individually.

The workflow uses a batch size of **2**, allowing multiple leads to be processed while controlling the execution flow.

### 7. Generate Email with Gemini AI

For each lead, the workflow sends relevant information to an LLM through the **Message a Model** node.

Gemini generates a simple recruiter outreach email based on the available lead information.

The generated content can include elements such as:

* Recruiter's name
* Company name
* Candidate introduction
* Relevant skills
* Job-seeking context
* Professional closing

### 8. Parse AI Output

The generated response is parsed and prepared for the email-sending node.

This ensures that the output generated by the LLM is transformed into the expected format.

### 9. Send Email with Gmail

The final email is sent automatically using the **Gmail** node.

The workflow then returns to the loop and processes the next lead.

## 🤖 AI Email Generation

The LLM is used to dynamically generate the email content instead of relying on one fixed template.

The model receives structured lead information and generates a concise professional message.

Example input:

```json
{
  "name": "Recruiter Name",
  "company": "Company Name",
  "email": "recruiter@example.com"
}
```

The generated message can then be passed to Gmail for delivery.
